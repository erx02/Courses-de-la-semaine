Les repas sont chargés depuis le fichier data/repas.json du dépôt GitHub. Modifiez ce fichier sur GitHub pour mettre à jour le menu de tout le monde. Vous pouvez aussi renseigner l’URL brute (raw) d’un autre fichier JSON hébergé sur GitHub.

Le fichier doit contenir un tableau de repas, avec name, icon, note et items. Le menu est rechargé dès l’enregistrement.
